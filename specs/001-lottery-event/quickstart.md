# Quickstart: 尾牙抽獎活動系統

本指南說明如何快速啟動並驗證抽獎活動系統的核心功能。

## Prerequisites

確保以下環境已設定：

```bash
# Ruby & Rails
ruby -v  # 3.4.1
rails -v # 8.0.2.1

# Node.js
node -v  # 18.20.0+

# SQLite
sqlite3 --version  # 3.x

# 已安裝依賴
bundle install
npm install
```

## 1. 資料庫設定

```bash
# 建立資料庫
rails db:create

# 執行 migrations
rails db:migrate

# 建立種子資料（包含測試管理者帳號）
rails db:seed
```

**種子資料內容：**
- Admin: `admin@weiya.local` / `password123`
- 測試活動（草稿狀態）含 3 個獎項
- 10 位測試參與者

## 2. 啟動開發伺服器

```bash
# 啟動 Rails + Vite
./bin/dev
```

開啟瀏覽器：
- 後台: http://localhost:3000/admin
- 前台: http://localhost:3000/events/1

## 3. 驗證核心功能

### 3.1 後台登入 (US6)

1. 前往 http://localhost:3000/admin
2. 輸入 `admin@weiya.local` / `password123`
3. 預期：成功登入，看到活動管理儀表板

### 3.2 建立活動 (US1)

1. 點擊「新增活動」
2. 填寫：
   - 名稱：2025 尾牙抽獎
   - 日期：選擇未來日期
   - 必填欄位：勾選「員工編號」
   - 允許重複中獎：否
3. 點擊「儲存」
4. 預期：活動建立成功，狀態為「草稿」

### 3.3 新增獎項 (US1)

1. 進入活動編輯頁
2. 點擊「新增獎項」
3. 填寫：
   - 名稱：頭獎 iPhone 15
   - 類型：禮品
   - 價值：35900
   - 數量：1
   - 顯示欄位：姓名、電話
   - 保密設定：姓名✓、電話✓
4. 預期：獎項建立成功，因為是禮品所以「需課稅」為否

5. 再新增一個：
   - 名稱：現金獎 $10,000
   - 類型：現金
   - 價值：10000
   - 數量：3
6. 預期：獎項建立成功，「需課稅」自動設為是

### 3.4 匯入參與者 (FR-006)

1. 準備 CSV 檔案 `participants.csv`：
   ```csv
   employee_id,name,phone,email
   E001,陳家銘,0912345678,chen@example.com
   E002,林小明,0923456789,lin@example.com
   E003,王大華,0934567890,wang@example.com
   ```
2. 點擊「匯入參與者」
3. 上傳 CSV 檔案
4. 預期：顯示匯入成功 3 筆

### 3.5 發布活動

1. 點擊「發布活動」
2. 預期：狀態變更為「進行中」

### 3.6 前台即時顯示 (US3)

1. 開啟新視窗前往 http://localhost:3000/events/1
2. 預期：顯示活動資訊與獎項列表（等待開獎狀態）

### 3.7 執行開獎 (US2)

1. 回到後台，點擊獎項旁的「開獎」按鈕
2. 預期：
   - 後台顯示中獎者（完整資訊）
   - 前台即時更新顯示中獎者（遮罩後）
   - 姓名顯示如：陳○銘
   - 電話顯示如：0912-XXX-678

### 3.8 參與者查詢 (US4)

1. 前台點擊「查詢我的結果」
2. 輸入員工編號：E001
3. 預期：
   - 若已中獎：顯示中獎獎項詳情（完整資訊）
   - 若未中獎：顯示「尚未中獎」

### 3.9 發放管理 (US5)

1. 後台進入「中獎管理」
2. 勾選一筆中獎記錄的「已發放」
3. 預期：發放狀態更新，記錄發放時間

## 4. 驗證邊界條件

### 4.1 重複中獎限制

1. 建立一個「不允許重複中獎」的活動
2. 開獎第一個獎項，記錄中獎者
3. 開獎第二個獎項
4. 預期：第一個獎項的中獎者不在候選名單中

### 4.2 獎項覆蓋設定

1. 建立活動（不允許重複中獎）
2. 新增獎項，勾選「覆蓋：允許重複中獎」
3. 開獎此獎項
4. 預期：所有參與者（包含已中獎者）都在候選名單中

### 4.3 已開獎項保護

1. 開獎一個獎項
2. 嘗試編輯該獎項
3. 預期：顯示錯誤訊息，無法編輯

### 4.4 活動密碼驗證 (US7)

1. 編輯活動，設定前台密碼：`weiya2025`
2. 開啟無痕視窗前往前台
3. 預期：要求輸入密碼
4. 輸入正確密碼
5. 預期：進入活動頁面

## 6. 常見問題

### ActionCable 連線失敗

```bash
# 確認 Solid Cable 設定正確
# 檢查 config/cable.yml 設定
# Rails 8 預設使用 Solid Cable (SQLite-based)
```

### 前端熱更新不生效

```bash
# 重啟 Vite
bin/vite dev
```

### 資料庫連線錯誤

```bash
# 確認 SQLite 資料庫檔案存在
ls -la db/*.sqlite3

# 重建資料庫
rails db:drop db:create db:migrate db:seed
```
